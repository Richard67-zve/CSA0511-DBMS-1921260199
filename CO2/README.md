## Local experiments and reproducibility

The recorded benchmark and query evidence was produced by running the included Python programs with Python 3.13.5 and SQLite 3.46.1. It is **local SQLite evidence**, not MySQL evidence or a production-throughput guarantee. The input populations are synthetic, deterministic fixtures generated with seed 4211. The declared cohort and policy rules used to make test queries meaningful are described in the report.

From this folder, run:

```bash
python Python_Scripts/benchmark_co2.py
python Python_Scripts/run_case_queries.py
python Python_Scripts/verify_design_equivalence.py
python Python_Scripts/higher_normal_forms_demo.py
python Python_Scripts/create_evidence_assets.py
```

`benchmark_co2.py` creates the three logical designs for 10,000, 100,000 and 600,000 observations and writes SQLite databases under `outputs/databases/`. Those binary database files are intentionally not included in the GitHub upload bundle because the largest file exceeds GitHub's ordinary 100 MB per-file limit; they are reproducibly regenerated by the first command. The remaining result tables, checksums, logs and charts are included.

## MySQL implementation

The MySQL scripts target **MySQL 8.0.16 or later** (for enforced `CHECK` constraints). The prepared run order is in `SQL/RUN_ORDER.txt`. In outline:

1. Execute `SQL/01_create_schemas_mysql.sql` in MySQL.
2. Install the optional connector with `pip install mysql-connector-python`.
3. Set `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD` and `MYSQL_DATABASE` environment variables.
4. Run `python Python_Scripts/load_mysql.py --observations 10000` (or `100000` / `600000`).
5. Execute the remaining SQL files as described in `SQL/RUN_ORDER.txt`.

**Verification status:** a live MySQL server was not available in the report-building environment. The MySQL DDL, loader, views and queries are supplied for reproducible MySQL execution, but they are not represented as having been run. The reported measurements, SQL query outputs and integrity errors are explicitly from the local SQLite verification path. See `Execution_Evidence/MYSQL_EXECUTION_STATUS.txt`.
