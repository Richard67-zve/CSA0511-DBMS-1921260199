## Execution evidence — read this first

The portable Python validation harness was actually run with the bundled scripts for **100, 1,000, 10,000 and 100,000 lenders**. The Task 12 shared-ownership logic demonstration and flat-file anomaly demonstration were also executed. Their outputs, timings, query result counts and constraint rejection messages are included in `outputs/` and `Execution_Evidence/`.

The portable harness uses Python's built-in **SQLite** module. Therefore, its timings and constraint messages are SQLite evidence, not MySQL evidence. The PNGs in `Execution_Evidence/Output_Captures/` are image renderings of captured stdout from those runs; they are not photographs or screenshots of a desktop terminal window. Full text logs are included beside them.

**MySQL status:** The MySQL DDL, loader and SQL validation scripts are provided, but they have **not** been executed against a live MySQL Server in the build environment. Do not describe the SQLite results as MySQL execution. If the assessor specifically requires MySQL-native evidence, run the commands below on a MySQL 8.0.16+ installation and add actual MySQL screenshots/logs.

## Run the MySQL implementation (when MySQL is available)

Requirements: MySQL Server **8.0.16 or later** and Python 3.10+.

Install the connector:

```bash
python -m pip install -r requirements.txt
```

Run from the parent repository root (the directory that contains `CO1/`):

```bash
mysql -u root -p < CO1/SQL/01_schema_mysql.sql
python CO1/Python_Scripts/load_mysql.py --size 100
mysql -u root -p meridian_museum < CO1/SQL/03_validation_queries.sql
```

The supported lender counts are `100`, `1000`, `10000`, and `100000`. To test each size independently, rerun the baseline schema first because it drops and recreates the assignment tables. The schema script is destructive to existing tables in the `meridian_museum` database: back up any data before running it.

Task 12 migration is run only after loading a baseline dataset and taking a backup:

```bash
mysql -u root -p meridian_museum < CO1/SQL/02_task12_shared_ownership.sql
```
